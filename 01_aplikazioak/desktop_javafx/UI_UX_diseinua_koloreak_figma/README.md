# desktop_javafx/UI_koloreak
## T1 Jatetxea - Italiar-Euskaldun Diseinu Sistema eta Figma Baliabideak

Karpeta honetan T1 Jatetxearen JavaFX aplikazioaren (Sukaldeko KDS, Barrako BDS eta Biltegiko Stock Kudeaketa) diseinua, koloreak, tipografia, logoa eta Figman garatzeko gidak daude.

### Edukia eta Fitxategiak

1. **`01_DISEINU_SISTEMA_ETA_KOLOREAK.md`**
   * Italiar-Euskaldun fusioaren filosofia kromatikoa.
   * Kolore-paleta ofiziala (HEX, RGB, JavaFX aldagaiak, erabilerak).
   * Tipografia eskala (H1, H2, H3, Body, Badges, KPIak).
   * Irisgarritasun eta WCAG kontraste arauak (irakurgarritasuna bermatzeko).

2. **`02_FIGMA_EGITURA_ETA_KOMPONENTEEKIN_GIDA.md`**
   * Figma proiektua antolatzeko egitura (Pages, Styles, Component Library).
   * 1180x750 px eta pantaila handietarako frame neurriak.
   * Komponente nagusiak (TopBar, Buttons, Badges, Tables, Cards).
   * Figmatiko diseinuak JavaFX-era 1:1 eramateko gomendio praktikoak.

3. **`03_JAVAFX_CSS_ESTILO_TXANTILOIA.css`**
   * JavaFX aplikazioan zuzenean txertatu edo kontsultatu daitekeen CSS fitxategi osoa.
   * Taula hautatuen kontraste zuzendua, egoera-txapak, botoiak eta txartelak.

4. **`04_LOGOA_ETA_IKUS_IDENTITATEA.md`**
   * Markaren izen proposamenak: "T1 Jatetxea · Osteria & Parrilla".
   * Sinbologia (oliba adarra, euskal haritza, egur-labea eta txingarra).
   * Logoaren aldaerak eta JavaFX-en integratzeko jarraibideak.

5. **Bektore Fitxategiak (SVG)**
   * `t1_logo_italo_euskalduna.svg`: Logo horizontal osoa (Figma-ra arrastatu daitekeena).
   * `t1_isotipoa.svg`: Ikono biribil karratua (app icon, favicon eta leiho txikiagoetarako).
