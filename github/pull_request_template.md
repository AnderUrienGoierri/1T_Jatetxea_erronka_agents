## 1T Jatetxea - Pull Request Proposamena

### 1. Deskribapena eta Testuingurua
<!-- Azaldu zer aldaketa egin den, zergatik eta zein beharri erantzuten dion -->

### 2. Aldaketa Mota
- [ ] `feat`: Funtzionalitate berria
- [ ] `fix`: Akats baten zuzenketa
- [ ] `refactor`: Kode-egitura hobekuntza
- [ ] `style`: Figma edo interfaze estilo aldaketa
- [ ] `docs`: Dokumentazio aldaketa
- [ ] `ci`: CI/CD edo DevSecOps hobekuntza

### 3. Eragindako Azpisistemak (Scopes)
- [ ] `api`: ASP.NET Core REST API (5050 ataka)
- [ ] `admin`: Admin IT Zentrala (5000 ataka)
- [ ] `desktop-csharp`: C# Windows Forms TPV
- [ ] `kds-javafx`: JavaFX Sukaldea KDS
- [ ] `web-php`: Web PHP Frontend (8085 ataka)
- [ ] `mobile`: Mugikor aplikazioak (Bezeroa / Zerbitzaria)
- [ ] `tv`: Android TV KDS
- [ ] `infra`: Docker / OPNsense / Cisco sareak

### 4. DevSecOps eta Kalitate Kontrol-Zerrenda
- [ ] **Zero Secret Leakage:** Ez da kredentzialik, gako pribaturik ezta pasahitz gogorrik gehitu.
- [ ] **Zero Emoji:** Ez dago emojirik kodean, iruzkinetan, dokumentazioan ezta komit-mezuan ere.
- [ ] **Conventional Commits:** Komit-mezu guztiek hitzarmena jarraitzen dute.
- [ ] **Figma Estandarrak:** Geruzen izenak bat datoz kodeko aldagaiekin (`btn*`, `txt*`, `tbl*`, `lbl*`).
- [ ] **Portu-banaketa mantendu da:** Admin panela 5000 atakan eta REST API 5050 atakan mantentzen dira.
- [ ] **Proba Lokalak:** Aldaketak lokalki konpilatu eta egiaztatu dira.
