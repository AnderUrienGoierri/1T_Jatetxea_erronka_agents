# Goierri Motors

Proiektuak Java 21 JDK eta JavaFX 21 erabiltzen ditu.

IntelliJ IDEAn, aukeratu Java 21 **File > Project Structure > Project > SDK**
atalean. Abiarazteko konfigurazioak beste JDK bat zehazten badu, hautatu Java 21
han ere (**Run > Edit Configurations > JRE**). Java 26rekin JavaFX 21ek
native access eta `sun.misc.Unsafe` abisuak sor ditzake.

Windowsen, `hasi_auto_aplikazioa.bat` fitxategiak instalatutako Java 21 JDK
bat bilatzen du aplikazioa abiarazteko.

Katalogoko prezioak, ezaugarriak eta pertsonalizazio-aukerak demo honetarako
orientagarriak dira. Argazkiek modeloa erakusten dute; bertsioa, kolorea eta
ekipamendua ez dira beti hautatutako konfigurazioaren berdinak.
[Argazkien egileak, jatorriak eta lizentziak](src/main/resources/eus/goierri/autoak/img/ARGAZKIEN_LIZENTZIAK.md)
fitxategian daude.
