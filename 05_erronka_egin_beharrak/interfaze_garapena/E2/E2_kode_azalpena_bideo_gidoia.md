## 1. Zer Kode Zati Aukeratu? (Zailtasun Teknikoaren Balorazioa)

Ebaluazioan **azaldutako kodearen zailtasuna** zuzenean kontuan hartzen denez, ez da komeni getter/setter sinpleak edo botoi baten kolorea aldatzea azaltzen denbora galtzea. Bi aplikazio nagusietan (**C# TPV** eta **JavaFX Gerentea**) zailtasun tekniko handieneko blokeak identifikatu dira, zuk garatu duzun zatiaren arabera aukera onena har dezazun:

| Aukera | Aplikazioa | Zailtasun handieneko kode-blokeak | Zergatik lortzen du nota altua? |
|---|---|---|---|
| **A Aukera** *(Gomendatua TPV garatu baduzu)* | **C# TPV** (`desktop_tpv_csharp`) | 1. `Theme.cs` — PerMonitorV2 DPI eskalatze-motorra (`ConditionalWeakTable` + `GraphicsUnit.Pixel`) eta GDI+ vektore-marrazketa (`DrawT1Logo`, `StyleButton`)<br>2. `UiPerf.cs` + `MahaiakForm.cs` — Win32 P/Invoke (`WM_SETREDRAW`), Reflection bidezko `DoubleBuffered` eta AJAX-moduko *in-place diff* freskatzea<br>3. `ProductImageCache.cs` — `ConcurrentDictionary` memoria-cachea, 3 mailako fallback-a eta `object-fit: cover` algoritmoa<br>4. `ApiService.cs` + `LoginForm.cs` — `async/await` REST bezeroa, fallback konexioa eta auto-berkonexioa | Maila baxuko Windows UI ingeniaritza (P/Invoke, Reflection, GDI+, DPI dinamikoa, memoria-kudeaketa eta 0-parpadeo rendering-a) + API asinkronoa. |
| **B Aukera** *(Gomendatua Gerentea garatu baduzu)* | **Gerente JavaFX** (`admin_desktop_java`) | 1. `KontrolagailuFabrika.java` + `JatetxeaKudeaketaAplikazioa.java` + `DiseinuNagusiaKontrolagailua.java` — MVC + Dependency Injection `Callback` fabrika eta `StackPane` bista-karga dinamikoa<br>2. `EkintzaAsinkronoak.java` + `ApiBezeroa.java` — `ExecutorService` daemon hari-igerilekua, `javafx.concurrent.Task<T>`, `@FunctionalInterface CheckedSupplier<T>`, `Gson` + `TypeToken.getParameterized` generikoa eta `ApiSalbuespena`<br>3. `KudeatzaileSaioa.java` + `MenuaKontrolagailua.java` — JavaFX `BooleanProperty`/`StringProperty` binding erreaktiboa + zerbitzu-blokeoaren logika + errezeten eskandalloa<br>4. `FakturakKontrolagailua.java` — `FilteredList<Faktura>` denbora errealeko iragazketa eta KPI asinkronoak | JavaFX profesionala: konkurrentzia garbia (UI haria blokeatu gabe), programazio erreaktiboa (*Properties/Bindings*), generikoak, DI fabrika eta MVC zorrotza. |

> **Oharra:** Bi aplikazioetan parte hartu baduzu, aukeratu bat ardatz nagusi gisa (5 minutu motz geratzen dira bietako kode sakona ondo azaltzeko) edo erabili **A** edo **B** gidoia osorik. Bi gidoiak **4 min 45 seg** ingurura daude neurtuta, **5:00** muga lasai errespetatzeko.

## 4. Nota Gorena Lortzeko Aholkuak eta Grabatu Aurreko Checklist-a

### Nola erakutsi kodearen zailtasuna 5 minututan
- **Ez irakurri lerroz lerro sintaxia** (*"hemen `if` bat dago..."*); azaldu **zer arazo tekniko** zegoen eta **zein diseinu-erabaki/patroi** erabili duzun ebazteko (*"UI haria blokeatzen zelako `Task<T>` + `ExecutorService` daemon-ak erabili ditugu"* edo *"WinForms-ek parpadeatzen zuelako `WM_SETREDRAW` + in-place diff erabili dugu"*).
- **Letra-tamaina handia IDEan:** Jarri zoom-a (`16pt–18pt`) bideoan kodea argi irakur dadin.
- **Fitxak aurrez irekita eta lerro zehatzean kokatuta:** Ez galdu segundorik karpetetan fitxategiak bilatzen grabatzen ari zaren bitartean.

### Grabatu aurreko Checklist azkarra
- [ ] **Docker / APIa martxan** (`jatetxea_mysql :3308` eta `jatetxea_api :5050`) azken 20 segundoko demo laburrerako.
- [ ] **Aukeratutako aplikazioa martxan** (TPV edo Gerentea), saioa hasteko prest.
- [ ] **IDEan 4 fitxategi zehatzak irekita**, aurkezpenaren ordena berean:
  - *A Aukera (TPV):* `Theme.cs` → `UiPerf.cs` → `MahaiakForm.cs` → `ProductImageCache.cs` → `ApiService.cs`
  - *B Aukera (Gerentea):* `KontrolagailuFabrika.java` → `EkintzaAsinkronoak.java` → `ApiBezeroa.java` → `MenuaKontrolagailua.java` → `FakturakKontrolagailua.java`
