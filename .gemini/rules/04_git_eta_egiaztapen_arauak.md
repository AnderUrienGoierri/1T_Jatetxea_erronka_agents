# Git eta Aldaketen Kudeaketa Arauak (Etengabeko Entrega)

1. **Aldaketa Txikien Egiaztapena eta Berehalako Igoera:**
   - Ez metatu aldaketa handiak edo zeregin desberdinak batera.
   - Urrats, funtzionalitate, klase, kontroladore edo egokitzapen bakoitza amaitu bezain laster, berehala egingo da `git commit` eta `git push` GitHub-era.

2. **Commit eta Push Derrigorrezko Protokoloa:**
   - Agenteak aldaketa bat baliozkotzen duen bakoitzean:
     1. `git add` bidez dagokion fitxategia(k) prestatuko ditu.
     2. `git commit -m "Deskribapen argia"` egingo du mezu esanguratsu batekin (adib. `feat(api): sortu ErreserbakController`, `fix(db): gehitu check iritziak`).
     3. `git push` egingo du aldaketa berehala GitHub-en islatzeko.

3. **Kode Egiaztatua Soilik:**
   - Push egin aurretik, egiaztatu kodea konpilagarria dela eta ez duela errore sintaktikorik.
