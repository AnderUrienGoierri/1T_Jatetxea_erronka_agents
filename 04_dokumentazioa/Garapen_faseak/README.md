## 13 Aplikazio eta Moduluak

Fase bakoitzean fitxategi hauek aurkituko dituzu:

1. `01_datu_basea.md` - Datu-Basea (MySQL 8.0 & PostgreSQL / Odoo)
2. `02_rest_api.md` - REST API Backend-a (ASP.NET Core C#)
3. `03_app_java_admin.md` - APP - Java Admin - Kudeatzailea (JavaFX)
4. `04_app_tpv_csharp.md` - APP - TPV - Zerbitzariak (C# WinForms)
5. `05_app_android_zerbitzariak.md` - APP - Android Zerbitzariak (Komandera Mugikorra / Tableta)
6. `06_app_android_tv_sukaldea.md` - APP - Android TV - Sukaldariak (KDS)
7. `07_app_java_sukaldea.md` - APP Java - Sukaldea (KDS Mahaigainekoa)
8. `08_app_java_biltegia.md` - APP Java - Biltegia (Stock eta Inbentarioa)
9. `09_app_chat_zerbitzaria.md` - APP - Zerbitzaria / Chat Internoa (Socket.IO)
10. `10_app_web_bezeroak.md` - APP - Web (Apache/PHP) - Bezeroak
11. `11_app_android_bezeroak.md` - APP - Android Bezeroak (Flutter Mugikorra)
12. `12_azpiegitura_digitala.md` - AZPIEGITURA DIGITALA (Makina Birtualak & Docker)
13. `13_azpiegitura_fisikoa.md` - AZPIEGITURA FISIKOA (Laborategia, Sareak eta Ekipoak)
