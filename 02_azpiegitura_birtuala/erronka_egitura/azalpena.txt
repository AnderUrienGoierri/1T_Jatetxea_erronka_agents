1. 3 MAKINA BIRTUALAK (VIRTUALBOX)
----------------------------------
- Erronka-OPNsense:
  * Suhesia eta bideratzailea (WAN, DMZ eta LAN segmentazioa).
  * Trafiko kontrola eta Zero-Trust segurtasuna.
- Erronka-Ubuntu (DMZ - 192.168.20.10):
  * Web zerbitzari publikoa (Apache 2.4 + PHP 8.2 / web_php).
  * Ataka: 80.
  * OPNsense bidez Windows Server-eko APIra konektatzen da (192.168.10.10:5000).
- Erronka-WinServer2025 (LAN - 192.168.10.10):
  * MySQL Datu-base nagusia (jatetxea_db) portu 3306.
  * ASP.NET Core REST API (.NET 10 C#) portu 5000.
  * TPV C# Desktop aplikazioa (Windows Forms).
  * Odoo 17 ERP (Erabiltzaileak, baimenak, fitxaketak, bajak) portu 8069.
  * Barne Txat Zerbitzaria (Socket.IO / WebSockets) portu 3001.
  * Sukaldeko Android TV / KDS panela portu 8086.
  * Active Directory (jatetxea.local), DNS eta DHCP.
